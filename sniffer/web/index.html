捕获与分析边界

  • 捕获：libpcap 在链路层取得可见报文，BPF 提前筛选。
  • 分析：链路层 → 网络层 → 传输层 → 应用特征。
  • TLS 显示握手/SNI，不解密 HTTPS 内容。
  • TCP 重组支持乱序、重传、重叠、序号回绕；IP 分片不重组。
  • 暂停仅冻结显示，捕获持续；停止会关闭抓包资源。
  • 内存满时淘汰最早报文；TCP 流同步移除，导出仅含保留窗口。

过滤语法

捕获过滤使用 libpcap BPF，例如 tcp port 8080 or icmp，开始捕获时生效，程序自动排除本地界面服务端口，避免捕获控制令牌和自身轮询流量。

显示过滤由独立解析器处理，可在捕获中修改：

http or tls
(tcp or udp) and not dns
ip.addr == 127.0.0.1 and tcp.port == 8080
length >= 100
info contains "GET"
process == curl
pid == 1234
flow == 2

支持 and / or / not、&& / || / !、括号。端口和数字支持 == != > < >= <=；文本支持 == != contains。HTTP 跨段识别结果在流追踪中显示；单包过滤按单包特征匹配。
