# Sniffer Design and Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在 macOS 实现符合课程 1A 的 GUI 网络嗅探器，并提供可核验的协议与流分析。
**Architecture:** ctypes/libpcap 捕获线程 → 有界会话及自主解码/流重组 → 本地 HTTP API → 浏览器三窗格 GUI。
**Tech Stack:** Python 3.9+ 标准库、系统 libpcap、HTML/CSS/JavaScript。
**Spec:** docs/superpowers/specs/2026-11-19-sniffer-design.md

## Global Constraints
- 当前 Mac 主要验收；不实现 1B；不联网发布仓库。
- 真实 NPS + GUI 是硬性要求；基本协议过滤，增强 NPA 和流追踪。
- 姓名、学号、远端 URL 与最终视频均不可伪造。

## Review Focus
- 截断/恶意长度/循环 DNS 指针：输出诊断，不越界或无限循环。
- TCP 乱序/重叠/回绕/缺口：不得静默生成不存在的数据。
- 抓包停止/导入/清空并发：禁止旧线程污染新会话。
- 浏览器跨源访问与报文载荷：拒绝跨源控制，文本安全渲染。
- 有界内存与错误过滤器：限额可见，过滤报错保持原会话。
