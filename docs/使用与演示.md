## 启动

在项目根目录：

```sh
./launch.command
```

该脚本先由系统 sudo 验证管理员密码，然后以普通用户运行界面服务器。只有实际启动捕获时，抓包辅助进程才通过 `sudo -n` 以管理员权限打开 BPF 设备。密码不传给 Python，不修改 `/dev/bpf*` 权限，不改 sudo 配置。请在同一终端启动；其他终端的 `sudo -v` 凭据可能不能共享。无需实时抓包可直接：

```sh
/usr/bin/python3 run.py
/usr/bin/python3 run.py --read samples/lab-demo.pcap
```

浏览器打开终端打印的地址；随机令牌在 URL 片段中，加载后移入 sessionStorage。不要只输入无令牌地址。若端口占用，加 `--port 8767`。`Ctrl+C` 退出。

## 真正的实时演示

1. 选择 `lo0`。捕获过滤填写 `tcp port 8080`，点击“开始抓包”。
2. 另一终端在不含私人文件的临时目录启动测试服务：

```sh
mkdir -p /private/tmp/prism-http-demo
printf 'UCAS Lab 1A HTTP capture demo\n' > /private/tmp/prism-http-demo/index.html
/usr/bin/python3 -m http.server 8080 --bind 127.0.0.1 --directory /private/tmp/prism-http-demo
```

3. 再开终端运行 `curl --noproxy '*' http://127.0.0.1:8080/`，界面应出现真实 TCP/HTTP 报文。
4. 点击 HTTP 报文，查看报文列表、协议字段树、HEX/ASCII 三窗格。切换 `http`、`tcp` 和 `ip.addr == 127.0.0.1 and tcp.port == 8080`。
5. 点击“追踪 TCP 流”，说明四元组归并、Seq/Ack、双向重组与时序。
6. 点击“暂停显示”，再发请求，观察继续显示后捕获计数增加；停止才关闭抓包。
7. 点击“导出”，清空后导入导出的 PCAP，核对数据。导出只包含当前保留窗口内匹配显示过滤器的报文。
8. 服务端按 Ctrl+C 结束，不需要抓取互联网流量。

一键真实捕获自检：`./verify_live.command`。它只捕获自建临时回环服务端口；成功会输出 `passed: true`，不保存用户网络数据。

## 进程关联演示

本工具使用普通用户 `lsof -nP -iTCP -FpcfPn` 的 socket 快照。在真实捕获期间点击“刷新进程快照”；应保持连接打开以避免短连接在快照前结束。可用 Python 创建一条持续连接：

```sh
/usr/bin/python3 -c 'import socket,time; s=socket.create_connection(("127.0.0.1",8080)); s.sendall(b"GET / HTTP/1.1\r\nHost: localhost\r\n"); time.sleep(45); s.close()'
```

在这 45 秒内刷新进程快照并查看“进程”页。`exact` 是完整四元组匹配；`listener` 是明确本地绑定地址和端口的回退推测；通配监听地址不用于猜测远端连接归属。匹配不等于逐包来源证明，离线报文禁止关联当前进程。刷新会清理已失效的归属。其他用户进程、短连接、PID/端口复用存在限制。

## 离线分析与增强案例

“载入演示”明确进入离线模式。`samples/lab-demo.pcap` 是独立构造的 21 个合成报文，不是实时抓包证据。案例包括 ARP、IPv4/v6、DNS、ICMP/v6、非标准端口 HTTP、TCP 握手/关闭、乱序与重传、带缺口的第二条流、TLS ClientHello SNI。

```sh
/usr/bin/python3 scripts/generate_sample.py
/usr/bin/python3 -m unittest discover -v
/usr/bin/python3 scripts/benchmark.py --packets 10000
```

显示过滤是安全的语法解析器，支持 `and/or/not`、括号和 `&&/||/!`，不执行代码。BPF 过滤由 libpcap 编译，实时开始时生效；界面服务端口自动排除，避免抓到控制令牌和界面轮询。`http` 是单包特征过滤；跨 TCP 段的 HTTP 可在流重组结果中识别，但不会反向把所有 TCP 段都标为 HTTP。
